04

Güvenlik bildirimi

Hassas bir açığı herkese açık kanalda paylaşma; destek merkezinde güvenlik kategorisini seç.

Güvenlik yolunu aç

Göndermeden önce

  1. Etkilenen sunucunun adını yaz; gizli davet veya token ekleme.
  2. Ne beklediğini ve ne olduğunu kısa adımlarla açıkla.
  3. Varsa yaklaşık saat ve görünen hata kodunu ekle.
  4. Hesap, ödeme veya lisans bilgilerini yalnız maskeli göster.

Asla paylaşma: bot tokenı, API anahtarı, parola, 2FA kodu, session cookie veya security key parolası.
